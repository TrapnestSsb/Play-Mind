Diccionario de variables:
- PlayerID: identificador del jugador (no se usa como variable)
- Age: edad
- Gender: género
- Location: ubicación geográfica
- GameGenre: género del videojuego
- PlayTimeHours: horas promedio por sesión
- InGamePurchases: compras dentro del juego (0 = No, 1 = Sí)
- GameDifficulty: dificultad del juego
- SessionsPerWeek: sesiones por semana
- AvgSessionDurationMinutes: duración promedio de sesión (min)
- PlayerLevel: nivel actual del jugador
- AchievementsUnlocked: logros desbloqueados
- EngagementLevel: OBJETIVO (High / Medium / Low)
